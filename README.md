# Miyori Kitsune

Локальное переносимое ядро Miyori Kitsune с веб-интерфейсом.

## Быстрый запуск

1. Скопируйте папку проекта на любой локальный носитель.
2. На Windows запустите MiyoriKitsune.bat.
3. Ядро выберет свободный локальный порт и автоматически откроет интерфейс в браузере.
4. Для остановки закройте окно ядра или нажмите Ctrl+C.

Требование первого этапа: Python 3.10+ (py -3 или python в PATH).

## Архитектура

- MiyoriKitsune.bat — единая точка запуска Windows.
- core/server.py — локальное ядро без внешних Python-зависимостей.
- web/ — адаптивный интерфейс.
- data/, logs/, config/ — создаются рядом с проектом при первом запуске.
- /api/health — проверка состояния ядра.
- /api/config — базовая конфигурация интерфейса.

## Меню

Основная зона: Чат с Miyori Kitsune → Рабочее пространство → Домашнее пространство → Настройки.

Отдельно внизу: Обновление проекта.

Отдельная пользовательская зона: Личный кабинет и Мобильное приложение.

## Portable mode

Ядро не использует абсолютные пути проекта: рабочий корень определяется от местоположения core/server.py. Поэтому папку можно переносить между дисками и носителями. Для полностью автономного запуска без установленного Python следующим этапом можно добавить локальный embedded Python runtime.
